Faulu Career Guidance System

A PHP and MySQL web application that helps students find careers that fit the skills they already have. Designed, built and deployed end to end as an independent product — including an admin panel to manage the careers and users behind it.

Role

The problem

Many students choose a course or career with very little structured guidance. Information is scattered, generic, and rarely starts from what the student is actually good at.

Faulu asks a student which skills they have, matches them against a database of careers and their required skills, and shows which careers fit and why.

The real app

The user journey

  1. 01Register & sign in

    A private account, protected by hashed passwords and CSRF tokens.

  2. 02Choose 3–5 skills

    The options come straight from the skills listed in the career database.

  3. 03Matching

    MySQL returns careers whose required skills include the ones chosen.

  4. 04Results

    Matched skills are highlighted on each career, and the results are saved.

  5. 05Dashboard

    Past results, saved careers and personal goals in one place.

How it's built

Interface

PHP-rendered pages with their own CSS, a responsive layout and small JavaScript touches such as show/hide password and remember-me.

↓ request  ·  response ↑
Application

PHP sessions with a timeout and ID regeneration, a CSRF token on every form, bcrypt password hashing, server-side validation including password strength, and failed-login counting.

↓ query  ·  rows ↑
Data

MySQL tables for users, careers, results, saved careers, goals and admins.

Key features

  • Secure accounts

    Registration, login by email or username, hashed passwords, CSRF protection, and password reset by emailed link.

  • Skills assessment

    Students pick 3–5 skills, drawn live from the careers in the database.

  • Career matching

    Matching careers are listed with the student's own skills highlighted on each one.

  • Search & career details

    Browse every career, with industry, education level and required skills.

  • Saved careers & history

    Students save careers and can come back to past results.

  • Goals tracker

    Students set, edit and complete personal career goals with target dates.

  • Profile & password

    Students update their details and change their password.

  • Admin panel

    Add, edit and delete careers, manage users, and see usage analytics.

Key decisions

Never trust the browser alone. Every form is checked again on the server, and every form carries a CSRF token.

Structure pays off. Separate config, helpers, page templates and an admin area made the app much easier to grow.

Design for the real user. A student on a phone needs short steps and clear results more than clever features.

What I'd improve next

Smarter ranking. Results are currently ordered by record, not by how many skills match. Next version: count the matches and rank by them.

Prepared statements everywhere. Login already uses them; the matching query escapes input instead, and I'd move it to bound parameters too.

Cleaner configuration. Keep database credentials out of the code, define every environment setting for local development, and set the secure-cookie flag from whether the site is on HTTPS.
